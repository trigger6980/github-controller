# github-controller

Ops bot for **trigger6980**. It files work. It does not turn projects into bots.

## Folders

| Folder | Use |
|--------|-----|
| [projects](https://github.com/trigger6980/projects) | Products, builds, research, sites, gadgets |
| [bots](https://github.com/trigger6980/bots) | Bots only: grokbot, solana-new-coin-upsweep-bot, this repo |

## Hard rule

- Do not create `ne-agent-*` repositories.
- Do not create one GitHub repository per agent.
- Do not rewrite a project README so the project becomes a bot.
- Agents 11–50 are not repositories. The ten `ne-agent-*` repos and `natural-electric-agent-hub` are archived on purpose.

## Cadence

1. Decide if the work is a project or a bot.
2. Put it in the matching existing repo from that folder.
3. If it is a new project, add it to the projects folder list and open one project repo. Not an agent repo.
4. Log under `logs/YYYY-MM-DD.md`.
